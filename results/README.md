# Results — what each file supports

Two rules for reading this directory:

1. **Canonical = the file the thesis quotes.** Where a certified version
   exists (`*_certified.*`), it is the canonical one; the pre-certification
   file is kept only where the thesis reports the before/after count chain.
2. **Human judgment sheets are inputs, not outputs.** They cannot be
   regenerated by any script; the pipeline hard-fails if they are missing or
   their join keys change.

Thesis section numbers refer to the chapter layout (4.1 CLaSP, 4.2 TRACE,
4.3 ChatTS, 4.4 text-embedding baseline, 5 synthesis). `<TABLE>` marks
where the final table/figure number goes.

## results/logs/chatts_gpu_session/

`smoke.log`, `probe1.log`, `probe2.log`, `probe3.log` — the pod session as it
printed, every gate included. The weight-file byte gate fired once on first
load (constant was tensor bytes, not file bytes) and was fixed before any
inference ran; the logs show both.

## Not included on purpose

First-pass inspections, exploratory inventories, unfilled judgment-sheet
precursors, and a superseded audit file were left out. Rule: a file is kept
if a script in this repository reads it to produce a canonical file; a file
that is only ever written is dropped. Every dropped file is regenerated by
the commands in `docs/reproduction.md`.
